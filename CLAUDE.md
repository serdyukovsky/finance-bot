# finance-bot — контекст проекта

Личный учёт денег Константина (Барнаул, UTC+7). Общение и все тексты для пользователя — **на русском**.
Константин — веб-разработчик, пишет код в режиме vibe coding. Объясняй коротко и по делу, без воды.

## Что это

- **Google Таблица** — хранилище данных и интерфейс. Разметку делает `sheets/finance_setup.gs`
  (Apps Script, запускается один раз из «Расширения → Apps Script», функция `setupFinance`). Таблица уже размечена и работает.
- **Telegram-бот** (`bot/`) — быстрый ввод и отчёты. Python 3.12, aiogram 3 (long polling), gspread 6, сервисный аккаунт Google.
- **Сервер**: Ubuntu, `194.34.239.95`, бот в Docker Compose (`restart: unless-stopped`), код в `~/finance-bot`.
- **Деплой**: push в `main` → GitHub Actions (`.github/workflows/deploy.yml`): pytest → SSH на сервер → `git pull --ff-only && docker compose up -d --build`.
- **Репозиторий**: https://github.com/serdyukovsky/finance-bot (приватный).

## Структура кода

| Файл | Что делает |
|---|---|
| `bot/main.py` | запуск, команды меню, обработчик ошибок, цикл напоминаний |
| `bot/handlers.py` | `Service` (синхронная логика: записи, переводы, проценты, отмена, напоминание) + aiogram-роутер |
| `bot/parser.py` | чистый разбор «450 магнит» / «+15000 зп» / «10545 > сбер» и подбор категории по ключевым словам |
| `bot/sheets.py` | весь доступ к таблице (gspread), кэш справочников 60 с |
| `bot/reports.py` | тексты ответов (HTML), формат денег |
| `bot/config.py` | переменные окружения |
| `tests/test_parser.py` | тесты парсера |
| `scripts/server_setup.sh` | первичная настройка сервера: Docker, ключи, клон |

gspread синхронный — из async-кода вызывать только через `asyncio.to_thread` (так уже сделано через `run()` в роутере).

## Таблица — это контракт. Не ломать.

Листы: **Главная, Операции, План, Долги, Месяц, Счета, Категории**.

**Операции** (бот пишет сюда по позициям колонок):
`A Дата | B Сумма | C Счёт | D Куда | E Категория | F Комментарий | G Источник (бот/вручную) | H Месяц (ARRAYFORMULA, yyyy-mm)`
- Строки только дописываются в конец (номер следующей = `len(col_values(1)) + 1`). Не вставлять в середину, не сортировать.
- Дата пишется серийным числом (дни от 1899-12-30), `value_input_option=RAW`.
- Порядок и смысл колонок A–G менять нельзя без правки `sheets.py`, формул в `finance_setup.gs` и миграции уже заполненной таблицы.

**Счета**: `A Счёт | B Тип (обычный/кредитка/кредит/долг) | C Ключ для бота | D Ставка | E Мин. платёж | F День платежа | G День выписки | H Начальный остаток | I Дата остатка | J Баланс (формула MAP) | K Дата сверки`

**Категории**: `A Категория | B Тип (расход/доход/служебная) | C Обязательная (чекбокс) | D Ключевые слова через запятую`

**План**: `A Название | B Сумма | C Повтор (ежемесячно/разово) | D День месяца | E Дата (разово) | F Счёт | G Статус (ждём/пришло/оплачено) | H Ближайшая дата (формула)`

**Главная** B8:B15: свободно, следующее поступление, дней до него, обязательные до него, можно в день, чистый капитал, общий долг, проценты/мес. D5:F — ближайшие платежи на 14 дней.
**Долги** A4:J13 — по долгу: остаток, ставка, проценты/мес, платёж, в тело, месяцев до нуля (NPER), переплата, сценарий «+доп. платёж» (B1). B17 — куда гасить сверх минимума (макс. ставка), B18 — уплачено процентов всего.

## Правила учёта

- Знак суммы: расход «−», доход «+». Отдельной колонки «тип» нет.
- **Перевод — одна строка**: сумма «−» со счёта C на счёт D, категория «Перевод». Баланс счёта = нач. остаток + сумма по C − сумма по D.
- Кредитки и кредит — это **счета с отрицательным балансом**. Покупка с кредитки — обычный расход с этого счёта.
- Платёж по долгу = перевод на долговой счёт. Бот один раз в месяц на такой счёт добавляет строку «Проценты и комиссии» с оценкой `остаток × ставка / 12` (комментарий «оценка — сверь с банком»).
- Расхождение с банком закрывается строкой категории «Корректировка».
- Служебные категории («Перевод», «Корректировка») не попадают в расходы. «Проценты и комиссии» — расход, обязательный.

## Бот: формат ввода и команды

`450 магнит` · `450 альфа такси` (счёт по ключу в любом месте) · `+15000 лендинг` · `5000 > нал` · `5000 нал > карта` · `10545 > сбер` · `2к кафе` · `10 545 > сбер`.
Не угадал категорию → inline-кнопки, выбранное слово дописывается в ключевые слова категории.
Команды: `/today /balance /debts /month /undo /help` + те же словами (сегодня, баланс, долги, месяц, отмена). Кнопка «↩️ Отменить» под каждой записью.
Напоминание в `REMINDER_HOUR` (21:00): если за день нет записей, платежи из «Плана» на 2 дня вперёд, дни выписки по кредиткам.
Доступ только для `ALLOWED_USER_ID`; чужим бот отвечает их Telegram ID.

## Секреты — никогда не в git

`.env` (BOT_TOKEN, SHEET_ID, ALLOWED_USER_ID, …) и `secrets/google.json` живут только на сервере, оба в `.gitignore`.
Шаблон — `.env.example`. Не выводить токены и ключи в чат и логи. Ключи для GitHub генерируются на сервере скриптом `server_setup.sh`.

## Как работать в проекте

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt pytest
python -m pytest -q
```
- Любая логика разбора — в `parser.py` и с тестом в `tests/`.
- Любой новый доступ к таблице — только через `bot/sheets.py`.
- Перед коммитом: `python -m pytest -q`. Коммиты на русском, коротко по сути.
- Если меняешь структуру листов — правь и `sheets/finance_setup.gs`, и `sheets.py`, и опиши миграцию существующей таблицы (скрипт разметки рассчитан только на пустую таблицу).
- Проверка на сервере: `ssh root@194.34.239.95 'cd ~/finance-bot && docker compose logs --tail 100'`.
